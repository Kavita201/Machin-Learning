# Email Classification using Naive Bayes

## Overview
This project implements a machine learning model that utilizes the Naive Bayes algorithm to classify emails as spam or not based on their content. The model is designed for efficient detection of spam emails and adaptability to new data.

## Features
- **Spam Classification**: Classifies emails as spam or non-spam using a Naive Bayes classifier.
- **Real-time Interactive Interface**: Users can input email content to test the classification in real-time.
- **Performance Visualization**: Displays performance metrics such as accuracy, precision, recall, and F1-score for better understanding of model effectiveness.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- streamlit (for the interactive interface)
- Matplotlib/Seaborn (for visualizations)
